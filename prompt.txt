# PROJECT OBJECTIVE

Redesign and build a **premium construction management company website** from scratch.

This must NOT look like a typical construction-company template.

Do not create a generic website with:

* repetitive rectangular cards
* excessive sections
* generic construction icons
* black/yellow construction colors
* stock photos of workers wearing helmets
* excessive gradients
* excessive glassmorphism
* huge amounts of text
* template-looking service cards
* unnecessary dashboards
* login/authentication
* backend functionality
* admin panels
* unnecessary forms
* over-engineered features

This is primarily a **premium public-facing brand website**.

The website should communicate:

**Construction Management + Precision + Trust + Experience + Quality + Premium Execution**

The experience should feel closer to a **premium architecture / infrastructure / engineering studio website** than a traditional construction website.

---

# CORE DESIGN DIRECTION

The design concept is:

## ARCHITECTURAL LUXURY × CONSTRUCTION PRECISION

The website should feel:

* premium
* bright
* minimal
* cinematic
* sophisticated
* spacious
* modern
* editorial
* trustworthy
* commercial
* architectural
* confident

The user should have the reaction:

> **"Wow, this feels expensive."**

Not:

> "Wow, look how many animations this website has."

Animation must be subtle and intentional.

Every movement should have a purpose.

# TYPOGRAPHY

Use a sophisticated combination of modern sans-serif typography and occasional editorial typography.

Primary font options:

* Manrope
* Inter
* Plus Jakarta Sans

Prefer **Manrope or Inter** for the primary interface.

For large editorial/display moments, you may use a refined serif such as:

* DM Serif Display
* Instrument Serif
* Cormorant Garamond

Do not use the serif everywhere.

Typography should feel architectural and editorial.

Use:

* large headlines
* generous whitespace
* tight but elegant typography
* strong hierarchy
* short paragraphs
* restrained uppercase labels
* carefully controlled letter spacing

Example visual language:

> BUILDING THE FUTURE,
> *ONE PROJECT AT A TIME.*

The typography itself should contribute to the premium feeling.

Hero → 10 cards → About card → Services cards → Project cards → Testimonials cards → Contact card.

**Who we are → What we believe → What we've built → How we work → Why clients trust us → Start a conversation**

Keep the number of sections intentionally limited.

**Less content. More impact.**

# ANIMATION SYSTEM

Animations are extremely important, but they MUST remain subtle.

The goal is:

**"This feels expensive."**

Not:

**"Look at all these animations."**

---

## 1. Smooth page transitions

Use subtle page transitions between pages.

No flashy transition effects.

---

## 2. Text reveal

When text enters the viewport:

Words or lines should gently slide upward.

Example:

Opacity 0 → 1

Y position slightly below → natural position.

Use smooth easing.

---

## 3. Image reveal

Images should initially be slightly masked.

As they enter the viewport:

mask opens → image reveals itself.

This should feel like an architectural photograph being uncovered.

---

## 4. Image zoom

On hover:

Scale approximately:

`1.00 → 1.03`

Use a smooth transition.

Never exaggerate.

---

## 5. Parallax

Use very subtle parallax on selected large imagery.

Avoid extreme movement.

---

## 6. Magnetic buttons

Implement subtle magnetic behavior for major CTAs such as:

**Request a Quote**

**View Project**

The button should gently respond to the cursor.

Keep the movement extremely small.

---

## 7. Cursor interaction

If a custom cursor is implemented, keep it minimal.

For example:

Hovering over a project can display:

**VIEW →**

Do not create a giant animated cursor.

---

## 8. Scroll animations

Elements should appear naturally as the user scrolls.

Do not animate every single element.

Some elements should simply remain static.

Premium design requires restraint.
